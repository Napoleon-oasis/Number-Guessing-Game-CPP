# Number-Guessing-Game-CPP

The **Number Guessing Game** is a console-based application developed using C++ that challenges players to guess a randomly generated number within a specific range. The game features three difficulty levels, each offering a different level of challenge to test the player's guessing ability, logical thinking, and problem-solving skills.

### Difficulty Levels

1. **Easy Mode:** Players guess a randomly generated number between 1 and 100 with 10 number of attempts.
2. **Medium Mode:** Players guess a number between 1 and 100 with 5 number of attempts.
3. **Hard Mode:** Players guess a number between 1 and 100 with 3 number of attempts, providing a greater challenge.

### Key Features
- **Random Number Generation:** Uses C++ randomization to generate a different secret number each round.
- **Three Difficulty Levels:** Allows players to choose their preferred level of challenge.
- **Interactive Gameplay:** Provides hints indicating whether the guessed number is higher or lower than the target.
- **Attempt Tracking:** Keeps track of the number of guesses used by the player.
- **Win/Lose Conditions:** Determines whether the player successfully guesses the number or runs out of attempts.
- **Replay Option:** Allows players to start another round without restarting the application.

### Programming Concepts Used
- Variables and Data Types
- Conditional Statements (`if`, `else if`, `else`)
- Loops (`while`, `do-while`, `for`)
- Functions
- Random Number Generation (`rand()`, `srand()`)
- User Input and Output (`cin`, `cout`)
- Switch Statements (`switch-case`)

**Project Objective:** To develop an interactive C++ game that demonstrates fundamental programming concepts while providing an enjoyable experience through different levels of difficulty.
